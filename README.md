# NEXORA CRM

Turn relationships into revenue.

NEXORA is a frontend-only CRM workspace for managing contacts, companies, deals, tasks, and pipeline reporting. It is a demo product: data lives in the browser session, and there is no backend, database, authentication, or external integration.

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL. `npm run build` typechecks the project and writes a production bundle to `dist`.

## Workspace

- `/` marketing site
- `/dashboard` pipeline overview
- `/contacts` and `/contacts/:id`
- `/companies`
- `/deals`
- `/tasks`
- `/calendar`
- `/reports`
- `/settings`
- `/help`

Press `Ctrl+K` inside the workspace to search contacts, companies, deals, and tasks.
